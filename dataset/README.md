# Registered Faces Dataset

This directory contains the dataset of registered faces for the Smart Door Raspberry Pi project. The dataset is used to store and manage facial data for authentication purposes.

## Structure

Each registered face is stored in this directory in an organized format. Ensure that the dataset is updated whenever new faces are registered or existing ones are removed.

## Usage

- The dataset is accessed by the Smart Door system for facial recognition.
- Ensure that all images are clear and meet the required resolution for accurate recognition.

## Notes

- Do not share or distribute the dataset with sensitive data or images.
- The dataset should only be used locally on the Raspberry Pi or a similar machine to ensure data security and privacy.
